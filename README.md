# QuranTV Cast Receiver

Custom Google Cast Web Receiver for the QuranTV app. Served by GitHub Pages at
https://ix06.github.io/qurantv-cast/ and registered as a Custom Receiver in the
Cast SDK Developer Console.

## Changing the background

One declaration in `style.css`, on the `body` rule, marked with a comment.
Replace the linear-gradient with `url("bg.jpg") center/cover no-repeat` and
commit the image beside it.
